# HeartEcho 项目说明（讨论稿）

> 一页看完，决定要不要一起做。技术细节都在另外的文档里，这份只讲**要做什么、你做什么、难不难、值不值**。

---

## 一、我们要做的是什么

**一个 AI 情感陪伴网页应用。** 说白了：

> 你注册一个账号，创建几个 AI 伴侣（自己起名字、设定性格和说话方式），然后跟它们聊天。每个伴侣会**各自**记住你对它说过的事、察觉你的情绪、在你几天没找它时主动来问候你，还会自己发朋友圈、跟你的其他伴侣互相评论。这是完全属于你一个人的空间，别的用户看不到你的任何内容。

和普通聊天机器人的区别，就在**它会记住、有情绪、会主动**这三件事上。

**三个具体场景**（答辩时也是演这几个）：

1. 你和小暖说"我养了只猫叫豆豆"。过两天再打开小暖，你问"我养了什么？"，它答"豆豆呀，它最近还好吗"。**每个 AI 伴侣各记各的**——你跟小星聊过的事，小暖不会知道。
2. 你发"今天上班好累啊"，它会先共情你、安慰你，而不是甩给你一堆建议；换一句"今天升职了！"，它的语气会明显更活泼。**它在后台识别你的情绪，据此调整怎么回你，但不会把情绪标签贴给你看。**
3. 你三天没上线，它主动发来消息："最近没见你，是不是项目很忙？"

## 二、做出来长什么样

- **登录 / 注册页**
- **对话页**——左边是人设列表（点谁就跟谁聊，一个人设一个对话），右边聊天窗口，AI 回复是一个字一个字"打"出来的
- **人设页**——创建、编辑、删除 AI 伴侣
- **朋友圈页**——你的 AI 发的动态，你的其他 AI 在下面评论，你也能点赞评论
- **用户画像页**——切换伴侣，看它各自记住了你的哪些事
- **日程页**（有时间才做）——在对话里说"明天三点提醒我开会"，到点它主动来提醒你

答辩时用手机 4G 打开公网地址，按顺序演一遍，10 分钟演完。

## 三、三个人分别做什么

| | 成员 1（我） | 成员 2 | 成员 3 |
|---|---|---|---|
| **负责** | Go 后端框架、登录注册、流式对话接口、Python AI 服务（有余量时加：日程抽取） | 前端框架、登录注册页、聊天界面、用户画像页 | 数据库表、人设功能、朋友圈、部署上线（有余量时加：日程页） |
| **接触的技术** | Go、Python、JWT 鉴权、SSE | Vue3、TypeScript、Pinia | Vue + Go + SQL + Docker |
| **难在哪** | 框架是大家的地基，不能出错 | 流式回复的前端解析（有点绕） | 部署（和写代码是两回事，纯环境摸索） |
| **工作量** | 最重，第 1 周尤其忙 | 中等 | 中等，但杂 |

**我为什么建议这么分**：每人都既有前端又有后端产出（不是"你只写页面"），这样最后按 GitHub 提交记录算贡献度时，三个人是均衡的。考核看的就是这个。

## 四、难度诚实说

不骗你们，这个项目**比失物招领之类的题目难**。具体难在哪：

| 真风险 | 说明 | 我们的兜底 |
|--------|------|-----------|
| **流式输出** | "一个字一个字往外蹦"这条链路跨了 4 层（浏览器 → Nginx → Go → Python），任何一层配错，表现都是"没有流式效果"，排查起来费劲 | 第 4 周有专门的分层验证方法；而且**第 2 周末是生死线**，过不了就砍功能 |
| **部署上线** | Docker、云服务器、Nginx —— 这跟编程能力关系不大，纯粹是环境踩坑 | 文档里每一步都写好了，照做；提前 2 天部署，留出修错时间 |
| **时间** | 4 周，还要上课 | 功能分 P0/P1，**有明确的砍功能顺序**（见第六节） |

**但有三件事能大幅降低难度**：

1. **文档已经全部写好了**——目录结构、接口字段、数据库表、每周做什么，都不用现想。
2. **可以全程用 AI agent 辅助写代码**——不懂的让它解释，卡住让它帮你 debug。
3. **接口契约提前冻结**——前端不用等后端，两边可以同时开工，不会出现"我写完了没接口可测"。

**最低门槛**：会用 Git、能把自己电脑上的开发环境跑起来、能看懂代码在干什么（不要求会从零写）。这三条如果有一条不满足，准备期补一下就行。

## 五、4 周怎么走

```
准备期 (1-2天)   配环境 + 建仓库 + 把接口字段定死
Week 1          注册 → 登录 → 刷新页面还是登录状态      ← 第一个里程碑
Week 2          跟 AI 流式对话，回复逐字出现            ← ⚠️ 生死线
Week 3          情感分析 + 记忆 + 主动消息
Week 4          朋友圈 + 部署上线 + 答辩预演
```

每周日合并代码、跑一遍完整流程、看看要不要砍功能。

## 六、如果时间不够，砍什么

**按这个顺序砍，从上往下**（1 最先砍，7 最后才考虑）：

1. 语音对话（本来就不做）
2. 情绪趋势图（本来就不做）
3. 人格演化
4. 用户画像页
5. 日程提醒（本来就是加分项，排在最后才开工）
6. AI 朋友圈
7. 主动消息 / 记忆系统（只有 Week 2 生死线没过才砍）

🚫 **绝不砍**：登录注册、人设、流式对话、情感分析——砍掉任何一个，硬性要求就不完整了。

**换句话说：最坏情况下，我们交出来的是一个"能登录、能创建 AI 伴侣、能流式聊天、能感知情绪并据此回应"的完整可演示系统。** 这个底是保得住的。

## 七、需要你们确认的三件事
